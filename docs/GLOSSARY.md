# Siaheh Glossary

- Product experience words (UI): `فضا`, `ثبت`, `تاریخچه`, `اعضا`
- Internal backend model: `Message` is the storage entity for a `ثبت` entry.
- `ثبت`:
An entry in space timeline. Can include text and multiple attachments.
- `Attachment`:
Any file linked to one entry (image, video, audio, document, generic file).
- `Space`:
Shared context for entries. Two kinds: `personal`, `space`.
- `Personal Space`:
Single-user mode space. Can be converted to `space` with explicit irreversible action.
- `Role`:
`owner`, `admin`, `view_all`, `member`.
- Visibility:
`view_all` can see all entries; `member` sees own entries unless policy changes.
- Public Profile:
`username`, `display_name`, `avatar`, `about`.
- Private Credential:
`phone` (for login/recovery only).
